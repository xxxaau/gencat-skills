# Sol·licituds

> Font: https://sistemadedisseny.gencat.cat/38669693e/p/690b45 · Font actualitzada el 2024-11-13 · Extret el 2026-10-28

Per a una sessió de suport, sol·licitar un nou component, modificar-ne un d'existent o informar d'una incidència, cal contactar amb l'equip mitjançant els formularis de sol·licitud disponibles.

- [Sol·licita un nou component o modifica'n un d'existent](suport-sollicita-components.md)
- [Sol·licita una sessió de suport](suport-sollicita-suport.md)
- [Informa d'una incidència](suport-informa-d-una-incidencia.md)

> Estem treballant per activar el procés de sol·licituds mitjançant formularis. Fins que aquest mecanisme no estigui disponible, per fer alguna de les sol·licituds especificades cal enviar un correu electrònic a [sistemadedisseny@gencat.cat](mailto:sistemadedisseny@gencat.cat).
