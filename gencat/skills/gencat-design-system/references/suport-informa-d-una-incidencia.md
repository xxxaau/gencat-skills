# Informa d'una incidència

> Font: https://sistemadedisseny.gencat.cat/38669693e/p/8196ed · Font actualitzada el 2024-11-26 · Extret el 2026-10-28

Informa de qualsevol incidència per assegurar la correcta funcionalitat del sistema de disseny.

Reportar les incidències trobades ajuda a millorar el sistema de disseny. Si es detecta algun error o problema mentre s'utilitza la plataforma, l'aportació és fonamental per identificar-lo i resoldre'l ràpidament.

Cal enviar un correu a [sistemadedisseny@gencat.cat](mailto:sistemadedisseny@gencat.cat) per descriure el problema, incloent-hi tota la informació possible i fent servir l'assumpte **"Incidència en el sistema de disseny"**.
