# Sol·licita suport

> Font: https://sistemadedisseny.gencat.cat/38669693e/p/5493f4 · Font actualitzada el 2024-11-13 · Extret el 2026-10-28

Sol·licita una sessió de suport per resoldre dubtes o rebre assistència en l'ús del sistema de disseny.

L'equip ajuda a treure el màxim partit del sistema de disseny, assegurant que la implementació sigui fluida i eficient. S'ofereixen diversos tipus de suport per garantir que l'equip disposi de les eines i coneixements necessaris per treballar amb el sistema de disseny de manera òptima. Sol·licituds de suport disponibles:

1. **Sessió *onboarding*:** sol·licita una sessió d'*onboarding* per a tu o per al teu equip. En aquesta sessió es fa una introducció detallada sobre els components, les guies d'ús i les millors pràctiques.
2. **Gestió d'accessos:** sol·licita la creació de nous accessos, gestiona permisos existents o soluciona qualsevol incidència relacionada amb les credencials d'usuari. L'equip ajuda a mantenir els accessos actualitzats i operatius.
3. **Assessorament tècnic:** ajuda per resoldre qüestions sobre la integració del codi, l'ús correcte dels components o qualsevol altre dubte tècnic que pugui sorgir durant la implementació.
4. **Assessorament de disseny:** els especialistes de disseny poden assessorar sobre com utilitzar els elements del sistema per garantir que el disseny sigui coherent, accessible i visualment atractiu.
5. **Altres sol·licituds:** si el cas no s'ajusta a cap de les categories anteriors però cal suport sobre el sistema de disseny, es pot contactar igualment amb l'equip.

## Com sol·licitar-ho
Cal sol·licitar suport per correu electrònic a [sistemadedisseny@gencat.cat](mailto:sistemadedisseny@gencat.cat) i incloure a l'assumpte **"Sol·licitud de sessió de suport"**.
