## Sol·licitar accés a Github

Per accedir al repositori del codi dels components del Sistema de Disseny cal tenir accés a **Github**, una eina que permet als equips de desenvolupament col·laborar eficientment en el codi, controlar les versions i actualitzacions dels components i automatitzar fluxos de treball.

Si encara no tens accés, cal sol·licitar-lo a [sistemadedisseny@gencat.cat](mailto:sistemadedisseny@gencat.cat) per poder començar a treballar amb el repositori del sistema de disseny.
