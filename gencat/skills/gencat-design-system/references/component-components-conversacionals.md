# Components conversacionals

Elements reutilitzables i modulars que s'utilitzen per a construir les interfícies d'usuari conversacionals.

> Els components conversacionals es troben en progrés.

## Identitat
- [Avatar](component-avatar.md): Per representa l’assistent virtual en una conversa amb

## Accions
- [Botó de xat](component-boto-de-xat.md): Per iniciar una conversa amb el servei d’assistència virtual.
- [Botó tornar a baix](component-boto-tornar-a-baix.md): Per tornar a l'últim missatge de la conversa

## Contingut
- [Missatge de xat](component-missatge-de-xat.md): Per representar la intervenció d’un participant.
- [Fonts de coneixment](component-fonts-de-coneixement.md): Per mostrar les fonts que ha generat una resposta.

## Introducció de dades
- [Camp d'entrada de xat](component-camp-d-entrada-de-xat.md): Per enviar missatges
- [Suggeriments](component-suggeriments.md)

## Contenidors i estructura
- [Capçalera de xat](component-capcalera-de-xat.md): Per proporcionar un lloc per a la marca i l'accés a funcionalitats globals.
- [Contenidor de xat flotant](component-contenidor-de-xat.md): Per doanr estructura.
- [Capçalera scundària de xat](component-capcalera-secundaria-de-xat.md): Per aportar context funcional i legal.
