# Com saber el teu codi intern de GICAR

> Font: https://sistemadedisseny.gencat.cat/38669693e/p/146e5b · Font actualitzada el 2025-03-19 · Extret el 2026-10-28

Per conèixer el codi intern de GICAR, cal seguir aquests passos:
1. Accedeix a l'enllaç següent i inicia sessió amb l'usuari de GICAR: https://autenticaciogicar1.extranet.gencat.cat/cgi-bin/codiintern.cgi
2. Un cop dins, cerca l'apartat on es mostra la informació de GICAR.
3. Localitza el camp anomenat `CODIINTERN=XXXXXXXX`, on "XXXXXXXX" correspon al codi intern.

Aquest codi és el que cal per sol·licitar accés al repositori de Github (vegeu [Accessos](suport-accessos.md) i [Github](suport-github.md)).
