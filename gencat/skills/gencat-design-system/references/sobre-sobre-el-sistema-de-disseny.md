# Sobre el sistema de disseny

> Font: https://sistemadedisseny.gencat.cat/38669693e/p/43eda2 · Font actualitzada el 2026-03-02 · Extret el 2026-10-28

Benvinguda al sistema de disseny de la Generalitat de Catalunya.

Des de la Generalitat de Catalunya s'ha desenvolupat un sistema de disseny pensat per unificar i estandarditzar l'experiència digital en els diferents àmbits institucionals. Aquest sistema té com a objectiu millorar l'accessibilitat i l'eficiència de les plataformes digitals governamentals.

## Per què s'ha creat el sistema de disseny?
El sistema de disseny neix amb l'objectiu d'unificar les pràctiques de disseny i assegurar una coherència en tots els productes digitals. L'objectiu és simplificar la feina dels equips de disseny i desenvolupament, proporcionant-los eines i recursos clars per agilitzar els processos de treball.
A més, un sistema de disseny compartit és clau per garantir una comunicació clara i eficaç entre els equips.

## Què hi trobaràs?
El sistema de disseny recopila tots els components, paletes de colors, tipografies i altres elements de disseny utilitzats en els projectes. Així mateix, detalla les directrius de disseny, les millors pràctiques i altres recursos útils per crear productes coherents.

## Qui ho fa servir?
El sistema de disseny és útil per a tots els membres dels equips de disseny i desenvolupament. Això inclou dissenyadors d'interfícies, desenvolupadors front-end, dissenyadors de producte i qualsevol professional implicat en la creació de productes digitals.
Addicionalment, també pot ser de gran ajuda per als clients i altres parts interessades, ajudant-los a entendre les directrius de disseny.
